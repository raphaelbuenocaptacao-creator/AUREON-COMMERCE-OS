# AUREON Commerce OS

Plataforma de inteligência para dropshipping, infoprodutos e marketing digital.

## Módulos

- Visão Geral
- Drop Hunter
- Info Hunter
- Spy Center
- Offer Builder
- Ads Lab
- Analytics

## Stack

- Next.js 16
- React 19
- TypeScript
- Lucide React
- Vercel-ready

## Objetivo

Centralizar descoberta de oportunidades, análise de concorrentes, construção de ofertas, criação de campanhas e leitura de performance em uma única plataforma.

## Próximas integrações

- Banco de dados PostgreSQL / Neon
- Autenticação
- Fontes reais de dados para mineração e monitoramento
- IA para score, copy e análise de oportunidade
- Planos e billing
